# 🎴 かるた読み手

競技かるた・百人一首の練習用Webアプリです。スマホ対応の無料ツールで、読み手なしでも本格的なかるた練習ができます。

🔗 **[アプリを開く](https://karuta-reader.vercel.app)**

---

## 特徴

- 📚 **プリセット内蔵**: 百人一首（全100首）・いろはかるた（江戸・全48首）をすぐに使える
- 📄 **ファイル読み込み**: CSV・TXT・Excelファイルから札を一括インポート
- 💾 **セット保存**: 自分のかるたセットを名前付きで保存・管理
- 🎯 **自動/手動モード**: 初心者から上級者まで練習レベルに合わせて選択
- ⏱️ **間隔設定**: 札と札の間隔を3秒〜自由に設定
- 🔊 **自然な読み上げ**: Kyoko音声（iOS標準）を使用
- 📱 **スマホ最適化**: iOSでもAndroidでもPCでも動作

---

## 使い方

### 1. 札を用意する

**プリセットを使う場合**
- 「📚 かるたを選ぶ」をタップ
- 「百人一首」または「いろはかるた」を選択

**自分の札を使う場合**
- 「📄 ファイルから読み込む」でCSV/TXT/Excelをアップロード
- またはテキストエリアに直接入力（1行に1枚）
- 「💾 このセットを保存」で次回から呼び出せる

### 2. 設定する

- **読み上げモード**: 自動（間隔タイマーあり）または手動（タップで進む）
- **間隔**: 3秒・5秒・10秒・15秒またはカスタム
- **速度**: 0.5倍〜2倍

### 3. 練習スタート

- 「開始する」をタップ
- 読み上げ中は「次の札 ▶」で早送り可能
- スペースキーでも次の札に進める
- 「一時停止」「終了」でいつでも停止

---

## ファイル形式

CSV・TXT・Excelファイルを読み込む場合は1行に1枚の形式で作成してください。

```
むらさめの つゆもまだひぬ まきのはに
ありあけの つきまちいでつる さどのしま
あさぼらけ ありあけのつきと みるまでに
```
