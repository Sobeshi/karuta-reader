# 🎴 かるた読み手アプリ

競技かるた・百人一首の練習用Webアプリです。

## 特徴

- 📷 **OCR機能**: 写真からかるたを自動読み取り
- 🎯 **自動/手動モード**: 練習レベルに合わせて選択可能
- 💾 **保存機能**: よく使うセットを保存
- 📚 **プリセット**: 百人一首・いろはかるた収録
- 📱 **スマホ最適化**: PWA対応

## 使い方

1. 「📚 かるたを選ぶ」でプリセットまたは保存済みセットを選択
2. または「📷 写真を追加」でかるたの写真から読み取り
3. 読み上げモード・速度・間隔を設定
4. 「開始する」で練習スタート

## 技術スタック

- HTML/CSS/JavaScript
- Tesseract.js (OCR)
- Web Speech API
- LocalStorage
